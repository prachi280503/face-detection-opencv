# 👁️ Face Detection using OpenCV

Real-time face detection using Python and OpenCV.
Detects faces from webcam and draws green rectangles around them!

## 🛠️ Tech Used
- Python 3
- OpenCV (cv2)
- Haar Cascade Classifier

## 🚀 How to Run
pip install opencv-python
python face_detect.py
